# FlareX
### Intelligence & Dataset Management Platform

**FlareX** is a full-stack intelligence and dataset management platform developed using React, FastAPI, and PostgreSQL.

The project focuses on authentication, session management, role-based access control, dataset exploration, and security-focused application development.

## Project Overview

FlareX combines a modern frontend with a Python backend and relational database to provide an integrated dataset management experience.

## Technology Stack

| Component | Technology |
|---|---|
| Frontend | React, Vite |
| Styling | Tailwind CSS |
| Backend | Python, FastAPI |
| Database | PostgreSQL |
| ORM | SQLAlchemy |
| Authentication | JWT |

## Key Features

- User authentication
- Session management
- Role-Based Access Control (RBAC)
- Dataset record exploration
- Search logging
- Administrative functionality
- Frontend and backend integration

## Security-Focused Development

Development work has included:

- JWT-based authentication workflows
- Server-side session validation and revocation checks
- Role-based authorization checks
- Frontend authentication error handling
- Safer URL handling
- Review of potentially unsafe HTML and DOM rendering patterns

These describe implemented development work and code-review efforts. They are not a claim of independent security certification or a guarantee that the application is vulnerability-free.
